# GridScalr 0.16.1

First public release since 0.13.3. This release brings custom count types, the
count schedule, touch navigation, faster startup through lazy-loaded features,
and the 0.14–0.16 maintenance work.

## Highlights

- Custom project count types with a name, glyph and quantity unit.
- Pieces per count object, so one placed object can represent several doors,
  windows, radiators or fixtures.
- A **Count schedule** with one quantity row per count type, a Count type column
  in **Markups**, count-type filtering and grouping, and count legend glyphs.
- Reusable count presets for new projects.
- Two-finger pan and pinch zoom on both the primary canvas and the reference
  pane, with pen priority, palm rejection and a long-press context menu.
- OCR, PDF exports, XLSX and TIF import load only when used; production builds
  no longer ship source maps.
- Internal refactors, direct UI tests, ESLint in CI and ADR 0001 for feature
  modules.

## Compatibility and upgrade notes

- The project-file schema is **21**. Projects created with schema 19, 20 or 21
  open directly; older projects migrate automatically when opened.
- Source PDFs and TIFs are still referenced by path and SHA-256, and are never
  modified.
- Existing measurement and drawing layers keep their colours. Layer colour
  defaults apply only to newly created layers.
- Quantity reports remain derived from item data; the XLSX workbook is generated
  on demand and never replaces the project's measurements.
- The Windows installer can upgrade an existing installation.

## Known limitations and build notes

- The installers are not code-signed. Verify the published SHA-256 checksums
  before running a downloaded file.
- The symbol pictograms are original vector interpretations, not certified
  SS-EN ISO 7010 reproductions.
- TIF import supports 1-bit CCITT G3/G4 scans. Other TIF codecs are not yet
  supported.
- The Linux GTK stack resolves `glib 0.18.5`, which has a medium-severity
  soundness advisory fixed in `glib 0.20.0`. Tauri's GTK 0.18 dependencies pin
  this generation; the Windows artifacts do not use this code path. The risk is
  tracked for a future Tauri/GTK upgrade.
- The published installers are Windows builds. Linux and macOS builds can be
  produced from source.
- See the [full limitations list](https://github.com/MajorJohnDoe/gridscalr/blob/main/docs/limitations.md).
