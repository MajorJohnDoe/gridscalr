# GridScalr 0.13.3

First public release since 0.7.2. This release brings the reference pane and
revision comparison, local text search and OCR, curve and volume measurements,
the 0.13.x reference and tooling improvements, and a release-hardening pass.

## Highlights

- Reference pane with **Same page**, **Revision** and **Drawing** sources.
- Revision comparison with side-by-side and overlay views, a markup difference
  list and a comparison PDF.
- Local PDF text-layer search and bundled English/Swedish OCR for scanned pages.
- Radius, diameter, arc, angle, slope and volume measurements.
- Curve, angle and slope labels that stay outside their geometry with leaders.
- Shared **Circle & arc** and **Angle & slope** tool buttons with variant
  flyouts.
- Distinct Symbol icon, Highlight colour palette, and signal-red default
  measurement layers.
- Save / Discard / Cancel when closing with unsaved changes.
- Automatic SHA-256 checksums in the Windows build.

## Compatibility and upgrade notes

- Project-file schema remains **19**. Older projects migrate automatically when
  opened.
- Source PDFs and TIFs are still referenced, checksummed and never modified.
- Existing layers keep their colours after upgrading. Only newly created layers
  use the new layer-default colours.
- The Windows installer can upgrade an existing 0.13.x installation.

## Known limitations and build notes

- The installers are not code signed. Verify the published SHA-256 checksums.
- The symbol pictograms are original vector interpretations, not certified
  SS-EN ISO 7010 reproductions.
- Only 1-bit CCITT G3/G4 TIF scans are supported.
- The Linux GTK stack resolves `glib 0.18.5`, which has a medium-severity
  soundness advisory fixed in `glib 0.20.0`. Tauri's GTK 0.18 dependencies pin
  this generation; the Windows artifacts do not use this code path. The risk is
  tracked for a future Tauri/GTK upgrade.
- See the [full limitations list](https://github.com/MajorJohnDoe/gridscalr/blob/main/docs/limitations.md).
