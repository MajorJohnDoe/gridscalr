# GridScalr 0.19.1

This is a patch release. It fixes a save and PDF-export failure introduced in
0.19.0, plus the drawing fixes found while testing that release.

## Fixes

- **Floor heating (GV) no longer breaks saving or PDF export.** In 0.19.0 the
  serpentine used SVG arc commands that the app's own path parser does not
  support. Saving could fail after the symbol was selected, and PDF export
  failed whenever a floor heating symbol was on the page. The symbol now uses the
  same quadratic curves as the rest of the schematic set, so canvas, selection
  and PDF share one geometry.
- **Symbol tags stay horizontal when a symbol is rotated.** The label keeps its
  position relative to the rotated glyph but is no longer turned with it. Canvas
  and PDF now agree; previously the PDF left the tag unrotated in the old
  position.
- **Marquee selection follows the geometry.** A drag box now selects only lines,
  polylines and areas it actually crosses, instead of anything whose bounding box
  it touches. A long diagonal is no longer selected by a click that never comes
  near it.
- **Target-layer picker follows the page.** The context-bar picker lists only
  layers that apply to the current page; an active layer from another page is
  marked **(other page)** instead of being silently replaced.
- **Circulation pump (CP) points left** with a smaller, left-shifted triangle, so
  the flow direction is visible at library size.
- **Heat exchanger (VVX)** is redrawn as a close parallel zigzag with five even
  folds and a wider gap between the media.

## Changes

- **Special tab in the symbol library.** Operation-card tools now live there
  instead of the tool rail. The I/O rail is the first entry, and its `Shift+R`
  shortcut was removed; open **Symbols** (`B`) and choose **Special**.
- **Larger, brighter symbol previews** in the library.
- **Drawing colours in two rows of five**, with dark grey (`#535353`), yellow and
  pink added, so no tool flyout needs horizontal scrolling.

## Compatibility

The project-file schema is **23**. Projects saved by 0.19.0 load normally. A
project that could not be saved in 0.19.0 can be saved with 0.19.1.

Existing items pick up the redrawn symbol artwork automatically because every
changed symbol keeps its id. Only the safety-valve arrow tip and the three-way
valve branch snap point move slightly.

## Platform notes

The builds are not code-signed or notarized. The Windows SmartScreen and macOS
Gatekeeper notes from 0.19.0 still apply.

## Verification

- Frontend unit tests (632), Rust unit tests, Playwright smoke tests, the count
  workflow, canvas regressions and packaged `--smoke-test` runs on Linux, macOS
  and Windows.
- `npm run symbols:catalog`, `npm run check:i18n`, `npm run check:docs`,
  `npm run check:versions`, `npm run lint`, `npm run format:check` and
  `npm run build`.
