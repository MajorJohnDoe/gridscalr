# GridScalr 0.19.3

This is a patch release. It adds blank pages to the page-source flow and extends
the operation-card symbol library with the valve, vessel, silencer and meter
symbols requested after 0.19.2.

## New

- **Blank A3 and A2 pages.** **File → New project…** and **Add pages…** now offer
  a blank page next to the PDF/TIF import and the operation-card templates. A
  blank page has no drawing frame, title block, revision table or sheet fields,
  so it is a free surface for notes, sketches, symbols and images. It appends at
  the end like every other page, shows a **Blank** badge and does not offer
  **Edit sheet fields…**. Blank pages are excluded from operation-card sheet
  numbering.
- **A clearer page-source dialog.** The source step now explains each choice and
  only shows the fields that apply. The primary button changes between
  **Choose file…**, **Create project**, **Add sheet** and **Add page**.
- **37 additional schematic symbols.** The operation-card library now has 156
  stroke-only symbols, including:
  - gate, globe, rotary, needle, diaphragm, plug, flanged, angle, relief,
    blowdown, spring-gate and self-operating release valves;
  - motor, hydraulic, solenoid and pilot actuators;
  - Y-strainers, diverters, self-draining valves and check valves;
  - four heating tank outlines, vertical and dished-end vessels, and expansion
    vessel variants;
  - drain and exhaust silencers, a compressor/vacuum pump, and a standalone
    district-heating meter panel;
  - a thicker alternative flow arrow.

## Fixes and changes

- **Existing valve stems reach the valve centre.** The stem line no longer stops
  short on hand, motor and hydraulic valve symbols.
- **The circulation pump points left.** It uses an upright, filled flow triangle
  so the direction is visible at library size.
- **Pipes and ducts draw freely on ordinary pages.** The 5 mm schematic grid
  remains on operation-card sheets only.
- **The reference library no longer duplicates valve body and inline-port
  helpers.** The symbol artwork is split into category modules under
  `src/features/schematics/symbols/`; the public registry and every symbol id,
  category, port and label are unchanged.

## Compatibility

The project-file schema is **23**. No migration is needed. Existing projects,
including operation-card sheets, open with the same content and the same
symbols.
