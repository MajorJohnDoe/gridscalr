# GridScalr 0.17.0

This is the platform-foundation release: GridScalr now ships for Windows,
macOS and Linux from the same tag, projects can be packaged and sent to another
person, and the desktop shell behaves like a normal application.

## Highlights

- **Windows, macOS and Linux artifacts** from one release build. Windows keeps
  the NSIS installer, MSI and portable executable; macOS gets a universal DMG
  and `.app.zip` for Intel and Apple Silicon; Linux gets an AppImage, `.deb` and
  `.tar.gz` for x86_64. One merged `SHA256SUMS.txt` covers every file.
- **Portable `.gridscalr.zip` packages** with a manifest, checksums and relative
  paths, plus opt-in exports and original scans.
- **Safer saving**: atomic replacement, backups and canonical source-path
  protection. A failed save never destroys the previous project.
- **Preferences separate from Project settings.** Panel layout, default layer
  colours, app stamp defaults and the interface language live on the computer;
  units, labels, snapping, categories, count types, quantities and project
  stamps stay in the `.gridscalr` file.
- **Local diagnostics and support path.** **Help → Copy diagnostics** and
  **Report a problem** produce an anonymised report, a rolling local event log
  records runtime failures, and autosave failures stay visible in the status bar
  until a save succeeds.
- **Desktop integration:** `.gridscalr` file association from the installers, a
  second launch focuses the existing window and opens the requested file, and
  the window remembers its size, position and maximised state.
- **One compact title row** with the menu, undo/redo, project identity and
  app-drawn window controls on Windows and Linux; macOS keeps its traffic
  lights. Rename the project from **Project settings** or with `F2`.
- **Bundled demo and quick start** on the welcome screen, with the demo copied
  to the app data folder so it can be edited and saved.
- **Localization foundation:** typed English and partial Swedish catalogs,
  System/English/Svenska selection, per-key fallback, and a CI gate that stops
  new hard-coded interface strings.
- **Packaged smoke tests** run the real app on Windows, macOS and Linux for
  every pull request and before release artifacts are uploaded.

## Platform notes

The builds are not code-signed or notarized.

- **Windows 10/11:** SmartScreen may warn on the installer. Choose **More info →
  Run anyway** after comparing the SHA-256 hash with `SHA256SUMS.txt`.
- **macOS:** drag GridScalr from the DMG to Applications, then approve the
  unsigned app through **System Settings → Privacy & Security → Open Anyway**.
  The DMG is universal.
- **Linux x86_64:** install the `.deb`, run the AppImage after `chmod +x`, or
  unpack the tarball. The `.deb` and `.rpm` desktop entries pass a
  double-clicked project to GridScalr; the AppImage does not yet forward the
  file because of an upstream Tauri limitation.

## Compatibility

The project-file schema stays at **21**; projects saved by 0.16.x open without
migration. The Swedish interface currently covers the strings added in 0.17 and
falls back to English everywhere else until the 0.18 translation pass.

## Known limitations

- Windows 11 snap-layout hover is not shown on the app-drawn title row.
- The portable Windows executable and the AppImage do not register the
  `.gridscalr` file association.
- File dialogs, menu clicks and drag-and-drop are covered by the manual install
  checklist, not by the automated smoke test.
- The Linux GTK stack still resolves the documented `glib 0.18.5` advisory until
  a future Tauri/GTK upgrade.
