# GridScalr 0.26.0

This release makes the three busiest panels easier to read and adds a real
operation card to the demo. The Layers panel becomes two clear sections with
page-scoped rows, the Pages panel becomes one flat list with the source named on
each card, and Preferences gains section cards, visible buttons and an
always-visible scrollbar. It also fixes a focus loss caused by autosave and makes
PDF export metadata deterministic.

The project-file schema stays **26**. No migration is needed.

## Download

Windows portable, NSIS and MSI builds, one universal macOS DMG and app zip, and
Linux AppImage, deb and tarball are published on the GitHub Release for
`v0.26.0`, together with `SHA256SUMS.txt`. The builds are unsigned; see
**Install** in the README.

## Layers panel

- **Two sections.** Drawing layers and measurement layers each have their own
  header, count and action strip. The **This page / All pages** switch is gone;
  the panel always shows the open page's layers, and a layer that only exists on
  another page appears when that page is opened.
- **Actions at the bottom of each section.** A plus button creates a layer of
  that section's kind. The eye and lock buttons hide, show, lock or unlock every
  selected layer, and the trash button deletes the selection, including a whole
  multi-selection, as one undo step.
- **Visible selection.** Every selected row is tinted, so a `Ctrl`/`Cmd` or
  `Shift` selection is visible on screen. Right-click one of several selected
  rows for **Hide selected**, **Show selected**, **Lock selected**, **Unlock
  selected** and **Delete selected**; the action applies to the whole selection.
- **Drag anywhere.** The grip handle is gone. Press and drag anywhere on a row,
  including the colour swatch, folder icon or name. The colour swatch now opens
  the colour picker on a click and starts a drag on a press-and-move. The drop
  line still shows exactly where the row will land and marks a nest target.
- **Search reveals items.** A search expands a layer that contains a matching
  item and lists only the matching items, instead of filtering only on the layer
  name.
- **Keyboard moves follow the screen.** `Alt` + arrow moves a layer among the
  rows that are actually shown on the page and kind, so a hidden layer on
  another page can no longer sit between two visible rows.
- The "Items are created in …" note is gone; the active layer stays visible in
  the context bar and Properties.

## Pages panel

- **One flat ordered list.** Document headings are replaced by a source line with
  a file icon on each card. The line appears only when the project uses more
  than one source drawing.
- **Clearer card.** `Sida 1 · 1191 × 842 pt` replaces `p.1 · …`, the page number
  is drawn on the thumbnail, and a template sheet is labelled **Mall** instead
  of **Blad**.
- **Filters only when needed.** The status filter row appears only when a page
  has a problem, and then shows **All** plus the problem types that match pages.
  A project with no problems shows no empty chips.
- **View options on the Pages tab.** Right-click the **Pages** tab for **Group by
  source**, **Show source on cards** and **Show page numbers on thumbnails**.
  The choices are stored per machine. Grouping is a view of the same ordered
  page list and never changes the page order.

## Settings and Preferences

- Each settings section is a card with a heading bar, border and consistent
  padding. Buttons are visible instead of ghost text, and destructive actions
  keep the red outline.
- The category pane scrolls on its own with an always-visible scrollbar, while
  the category menu stays in place. The scrollbar is drawn by the app so it does
  not depend on the platform's overlay scrollbars.
- Data is split into **Autosave recovery**, **Rolling backups**, **Recovery
  data** and **Recent projects and drawings**. Recovery status is shown as
  chips, and the recent-file list has one row per file with a **Remove** action
  and a **Missing** chip.

## Demo project

The bundled demo now has a fourth page: an A3 operation card sheet (`LB01`) with
**146 objects** on four drawing layers and one measurement layer, including
schematics for a heat exchanger, fans, valves, dampers and ducts. The demo also
gains a template document, and the title row names the current page's source
drawing. The demo is still generated reproducibly with `npm run docs:demo`.

Two unused documents, an embedded TIF that no page referenced and a network
source path were removed from the supplied project before it became the demo.

## Fixes

- **Autosave no longer steals focus.** Every autosave refresh used to re-render
  the whole shell, replacing the focused field once per interval. A summary
  refresh now re-renders only when no project is open, so typing in Properties or
  a panel field is not interrupted.
- **Deterministic PDF export.** Export metadata is written from the project's
  timestamp instead of the wall clock, so two exports of the same project are
  byte-identical (F-043).
- The welcome screen now offers **New project…**, which opens the same source
  chooser as **File → New project…**, including the empty-project start.

## Upgrade notes

- Schema 26 is unchanged from 0.25.0. Projects saved by 0.25.0 open directly.
- Page-list grouping and the source line are per-machine view options, not
  project data and not part of a package.
- The demo now has four pages; a previously copied demo folder in the app data
  directory keeps its old copy until it is deleted.
