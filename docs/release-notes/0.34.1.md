# GridScalr 0.34.1

Internal architecture hardening. There is no user-facing behavior change and no
project-file change; the schema stays 28.

## Boundaries and state

- Every feature module now has an enforced public `index.ts`; imports that
  reached into feature internals were moved to the public surface.
- A runtime import-cycle gate (`npm run check:cycles`) follows value imports and
  value re-exports and fails CI on a new cycle. The repository baseline is zero;
  the last runtime cycle was removed by moving app-level page actions and the
  shared ID helper to their proper layers.
- The quantities panel moved from a 222-line UI file with eleven module-level
  variables to a feature module with a pure filter/cache model, one state object
  and tested rules.
- The pure Markups table logic moved out of the DOM row module, and the shared
  list filter rule moved to `src/model` so a row model no longer pulls a UI
  feature barrel into its module graph.
- The first typed item commands (`resetItemLabelPlacement`,
  `setItemCustomValue`) replaced inline project mutations in the inspector and
  custom-field editor.

## Compatibility

- No schema change; schema 28 is unchanged.
- No shortcut, menu, panel or report workflow changes, so the user guide and
  screenshots are unaffected.
