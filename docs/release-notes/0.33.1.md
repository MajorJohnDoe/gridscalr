# GridScalr 0.33.1

A fix release for the drawing background while zooming and panning. No schema
change; the project-file schema stays 28.

## Fixed

- **The drawing no longer blanks and redraws while you pan or zoom.** The page
  raster keeps the last complete bitmap on screen underneath the new one, and a
  coarse whole-page underlay sits beneath both, so a zoom step or a pan never
  flashes the page white before it refills.
- **Tiles are anchored to the page, not to the visible crop.** Every pan used to
  move the crop origin, which changed every tile key and forced a full
  re-render of the visible drawing. The grid now uses page-space columns and
  rows at the current render scale, so a pan keeps every tile that is still on
  screen and renders only the newly exposed edge. Markups were already reused
  during a gesture; the drawing behind them now behaves the same way.

## Unchanged

- The raster at rest is still rendered at the exact zoom and device scale, so a
  settled view is pixel-identical to the previous release.
- The 64 MiB tile budget, the full-page fallback when `createImageBitmap` or
  `OffscreenCanvas` is missing, and the read-only reference, comparison and
  split-view paths.
- Everything from 0.33.0: the grouped File menu, **Send by e-mail**, and the
  measured performance work (p95 edit, gesture redraw and raster time).

## Verify

Pan across a drawing and zoom in and out. The drawing should stay visible and
move continuously, sharpening as the new tiles arrive, with no white flash and
no full redraw on every pointer move.
