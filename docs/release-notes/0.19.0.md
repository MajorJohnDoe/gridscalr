# GridScalr 0.19.0

This is the operation-card symbol release: the schematic set has been reviewed
against the drawings used for the operation cards, the gaps found while drawing
them are filled, and the library grows to **119 schematic symbols**.

## Highlights

- **Reviewed symbol artwork.** The radiator, floor heating, filter, check valve,
  three-way valve, safety valve, circulation pump, heating coil and cooling coil
  follow the reviewed drawings. Supply and return now sit on the body edges, so
  the symbols no longer look like ordinary valves or carry protruding stubs.
- **Check valves are distinguishable.** A filled seat band marks the outlet, both
  on the check valve (BV) and on the new three-way check valve (3BV). A plain
  valve (V) covers the body without a seat band.
- **New operation-card symbols.** Plain valve (V), three-way check valve (3BV),
  single-pole switch (S1) and three-pole switch (S3). Together with the earlier
  mixer, flow arrow, expansion-vessel variants and reviewed ventilation symbols,
  the schematic set now contains 119 symbols.
- **Flow direction is visible.** The circulation pump has a filled arrowhead and
  the safety valve discharges downwards, so direction reads at library size.
- **Move to layer follows the page.** The right-click menu, Properties and the
  Markups layer column now list only layers that apply to the selected items'
  pages, matching the Layers panel's **This page** scope. The menu also appears
  when a single alternative exists, instead of requiring two.
- **Selection and snapping.** Multi-selections scale together, symbol selection
  edges are tighter, and drawing honours the visible snap targets while the
  gesture is in progress.

## Compatibility

The project-file schema is **23**. Projects saved with schema 22 and older load
normally and migrate when opened; there are no manual steps. A project saved by
0.19 should be opened with 0.19 or later.

Existing items pick up the new symbol artwork automatically because every changed
symbol keeps its id. Only the safety-valve arrow tip and the three-way valve
branch snap point move slightly; all other connection points are unchanged.

Source PDF and TIF files are still referenced by path and SHA-256 and are never
overwritten. The local-first guarantees, portable `.gridscalr.zip` packages and
three-platform release artifacts are unchanged.

## Platform notes

The builds are not code-signed or notarized.

- **Windows 10/11:** SmartScreen may warn on the installer. Choose **More info →
  Run anyway** after comparing the SHA-256 hash with `SHA256SUMS.txt`.
- **macOS:** drag GridScalr from the DMG to Applications, then approve the
  unsigned app through **System Settings → Privacy & Security → Open Anyway**.
  The DMG is universal.
- **Linux x86_64:** install the `.deb`, run the AppImage after `chmod +x`, or
  unpack the tarball.

## Known limitations

- The full user guide and workflows remain English-only in 1.0. The Swedish UI
  includes the Swedish quick start and an explicit English fallback (#57).
- Custom symbol uploads and symbol quantities in the procurement report are not
  supported; the built-in library is vector-only.
- The symbol pictograms are original vector interpretations, not certified
  SS-EN ISO 7010, SS-EN ISO 14617 or IEC 60617 reproductions.
- The Linux GTK stack still resolves the documented `glib 0.18.5` advisory until a
  future Tauri/GTK upgrade (#21).
