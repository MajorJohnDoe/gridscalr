# GridScalr 0.21.0

This release finishes the post-0.20 module splits and adds the light, grey and
navy themes. It is a code-health and presentation release; the project file and
export formats are unchanged.

## Themes

- **Four palettes.** The default dark jade theme is unchanged. **Light**,
  **Grey** and **Navy** are selectable in **Settings → Preferences → General**.
- **System mode.** The default follows the operating system: dark uses jade and
  light uses the light-green palette. Theme changes apply immediately and persist
  across restarts.
- **No first-paint flash.** An external `boot-theme.js` applies the stored theme
  before the app loads, without adding an inline script under the CSP.
- **Drawing content stays fixed.** Grid, selection, handles, measurements,
  labels, annotations and symbols keep their colours. Only UI chrome and the
  canvas surround change; PDF exports are untouched.
- **Contrast gate.** `npm run check:themes` verifies every palette defines the
  token contract and meets WCAG AA contrast for text and controls.

## Code health

- **PDF export split.** `src/pdf/pdfExport.ts` is now a 138-line entry point and
  page orchestrator. Export options, crops, fonts, images, geometry, labels,
  legend and every item family live under `src/pdf/export/`. `exportProjectPdf`
  and `pdfCropBoxForViewport` remain public.
- **Inline editors split.** `CanvasEditorController` stays the public surface;
  text, textbox, label and annotation sessions live under `src/canvas/editors/`.
- **App flows extracted.** Sheet, image, document, page, scale, package and
  diagnostics flows moved into focused `src/app/` modules. `App.ts` is 999 lines
  and only wires, dispatches shortcuts and exposes the test bridge.

The existing content-stream, sheet, comparison, editor, canvas, count, touch and
visual regression suites protect these moves. No export layout or user workflow
changed.

## Compatibility

The project-file schema remains **23**. No migration is needed. Existing
projects, packages, reference sessions and exports open unchanged.

## Verification

- Frontend unit tests and coverage, Playwright UI, canvas, count, touch and
  visual regression suites.
- Theme token completeness and WCAG AA contrast checks for all four palettes.
- Rust unit tests, `cargo fmt` and `cargo check`.
- Packaged `--smoke-test` runs on Linux, macOS and Windows from the release
  workflow.
- `check:versions`, `check:docs`, `check:file-budgets`, `check:i18n`,
  `check:themes`, `format:check`, `lint`, `tsc --noEmit`, `build`, `site:build`
  and `site:check`.
