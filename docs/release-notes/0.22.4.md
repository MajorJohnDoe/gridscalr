# GridScalr 0.22.4

This release fixes touchpad pinch-to-zoom on Windows.

## Touchpad zoom

- **WebView2 pinch is enabled.** The Windows webview now enables pinch zoom
  instead of swallowing the gesture, so the canvas receives the same wheel
  events as a browser.
- **Touchpad-sized deltas zoom.** Pinch events arrive with much smaller
  `deltaY` values than a mouse wheel. They now use a dedicated sensitivity, so
  each gesture is visible and smooth instead of appearing to do nothing.
- **Wheel delta modes are normalized.** Line- and page-based wheel events are
  converted to pixels before zooming.
- **Ctrl + mouse wheel is unchanged.** A full wheel notch keeps the previous
  zoom step, and two-finger scroll still pans.

## Compatibility

The project-file schema remains **23**. No migration is needed.
