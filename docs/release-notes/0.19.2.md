# GridScalr 0.19.2

This is a patch release. It collects the drawing fixes and small tool
improvements reported after 0.19.1.

## Fixes

- **Pipes and ducts follow the pointer.** Drawing a short run no longer jumps in
  5 mm steps on ordinary drawing pages, and the first click no longer lands away
  from the crosshair. The 5 mm schematic grid now applies only to operation-card
  sheets. Geometry snapping and the default horizontal/vertical pipe segments are
  unchanged; `Shift` still gives a free angle while drawing.
- **Shift works while editing lines and pipes.** Dragging a line or arrow
  endpoint, or a pipe vertex, now constrains the segment to 45° steps. A pipe
  vertex is constrained against the previous vertex (the next vertex for the
  first point); a line or arrow uses its other endpoint. The lock works on
  rotated items too.
- **The I/O rail keeps the symbol library open.** Arming the rail from the
  Special tab now leaves the tab and tile selected like every other symbol,
  instead of jumping back to Layers.
- **Colour swatches have a working eyedropper.** The native colour picker's
  eyedropper does nothing in some desktop webviews. Every colour swatch now has a
  pipette button that samples the rendered PDF and markup layers. Click the
  pipette, then click a colour on the drawing; `Esc` cancels. It works for item,
  layer, tool, line-type, preference and text-editor colours.

## Changes

- **Rectangle and Ellipse share one tool-rail button.** Long-press, right-click,
  or choose **Shapes** in the context bar to open the shape menu. It offers
  **Rectangle, filled**, **Rectangle, outline only**, **Ellipse, filled** and
  **Ellipse, outline only**, plus colour presets, a custom colour with the new
  pipette, stroke width and solid/dashed.
- **Outline is the default for new shapes.** An outline shape has no fill and is
  hit-tested only along its outline, so the objects inside a box stay selectable.
  Filled shapes keep the previous click-blocking interior. `R` and `O` still
  select Rectangle and Ellipse.
- **Existing shapes can change fill and line style.** Properties now has a
  fill on/off switch and the solid/dashed selector for rectangles and ellipses.
  Dashed shapes render on the canvas and in PDF export.

## Compatibility

The project-file schema is **23**. No migration is needed. Existing filled
rectangles and ellipses keep their stored fill; the outline default applies only
to shapes created after this release.
