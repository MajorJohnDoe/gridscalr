# Quick start

GridScalr measures PDF and scanned TIF drawings and turns the measurements into
procurement quantities. Everything stays on this computer.

## 1. Open a drawing

Choose **File → Open drawing…** and pick a PDF or TIF. You can also open the
bundled demo from the welcome screen. New drawings are appended to the project;
the source file is never modified.

## 2. Calibrate the page

Choose **Calibrate** in the tool rail and click the two ends of a known
dimension. Enter its real length and choose the unit. If the drawing states its
scale, use **Manual scale…** in the status-bar scale chip instead.

The page scale chip shows the current scale. It also lets you lock the scale,
apply a manual scale to all pages, or clear it.

## 3. Measure and count

- **Length** measures a polyline. Press Enter or double-click to finish.
- **Area** measures a polygon, rectangle or ellipse. Choose **Add** or
  **Deduct** in the context bar.
- **Count** places a count symbol. Choose the count type, category and room; set
  pieces per object for doors with several leaves.
- Use the other measurement tools for radius, diameter, arc, angle, slope and
  volume.

The **New measurement** popover sets the category, room, count type and area
mode for the next item. Properties lets you change a placed item.

## 4. Review and export

Open **View → Quantities…** for the live quantity summary. Export it as CSV,
Excel or PDF from the same dialog. Project metadata and a report logo are set in
**Settings → Project settings…**.

## Tips

- Hidden items and hidden layers are excluded from reports and exports.
- Locked items stay visible and exportable but cannot be edited.
- Press `Ctrl/Cmd+S` to save. Autosave only protects against a crash.
- Press `F1` for the full user guide.
