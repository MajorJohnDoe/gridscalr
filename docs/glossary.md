# Product glossary

Canonical English and Swedish terms for the interface, reports and help. Use
these terms consistently when adding catalog keys. The English term is the
stable identifier in the project file; only the displayed text is translated.

| English | Swedish | Notes |
| --- | --- | --- |
| takeoff | mängdning | The act of measuring drawings to produce procurement quantities. |
| markup | markering | Any measurement, drawing or symbol placed on a drawing. |
| layer | lager | A measurement or drawing layer. Layers are never mixed. |
| quantity | mängd | A calculated length, area, volume, count, angle or slope. |
| count | antal / räkna | **Antal** is the noun and quantity type; **räkna** is the tool/action. |
| count type | antalstyp | A door, window, fixture or custom counted object. |
| count schedule | antalstabell | The quantity row per count type, not a door/window schedule. |
| pieces per object | delar per objekt | Multi-piece count objects such as a double door. |
| waste | spill | The percentage added for cutting and breakage. |
| order quantity | beställningsmängd | Net quantity after waste and rounding. |
| reference view | referensvy | The read-only same-page or revision pane. |
| scale | skala | Drawing scale such as 1:100 or a calibrated points-per-metre value. |
| calibration | kalibrering | Measuring a known dimension to derive the scale. |
| page scale lock | sidans skallås | Prevents a page scale from changing accidentally. |
| properties | egenskaper | The right-hand inspector for the active layer and selection. |
| project settings | projektinställningar | Settings stored in the `.gridscalr` file. |
| preferences | inställningar | App-level settings stored on this computer. |
| deduction area | avdragsarea | An area subtracted from a gross measurement. |
| revision cloud | revideringsmoln | A cloud markup around a changed area. |
| drawing export | ritningsexport | The flattened PDF export of drawings and markups. |
| quantity report | mängdrapport | The A4 PDF report and its CSV/XLSX equivalents. |

## Rules

- Do not translate stable project values such as category names, room names,
  symbol ids, layer names or file paths.
- Keep the English word as the search synonym when a Swedish label replaces it.
- When a term changes, update this glossary together with the catalog, the user
  guide and the report headings.
