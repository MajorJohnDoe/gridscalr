### Completed work

- `orderFor()` in `src/pdf/export/ocg.ts` now writes the ISO 32000-1 Table 101

### Decisions

- ISO array form is the shipped form; the heading dictionary is gone.
- Repeated layer name for a group that owns items. A renamed heading would
  invent a translated label not stored in the project; content outside the
  heading would split one layer into two top-level entries. Both rejected in
  ADR 0016.
- Serialization-only change: no schema change (stays 26), no version bump, no
  UI string, no flattened-content change, OCG export stays opt-in.
