#### Completed

- Added `docs/security-audit.md`: threat model, asset list, trust boundaries,
  capability-by-capability review, CSP review in production and development,
  IPC command review, filesystem and package checks, frontend injection review,
  npm and Rust dependency results, and sixteen findings with evidence, impact,
  proposed fix and acceptance criteria.
- Recorded F-028–F-043 in `docs/plan/foundation-findings.md`.
- Updated `SECURITY.md`: supported versions, the project/package trust model,
  the page and worker CSP expectation, and the 1.0 security gate.
- No production code, dependency, workflow, schema or version change.

#### Decisions

- Phase 1 is audit-only. No production fix was made because there is no P0.
- No P0 and no P1. Eight P2 and eight P3 findings; all are assigned to phases
  2–5 or to a proposed new issue.
- The page loads two CSP policies: the Tauri header and a static meta tag in
  `index.html`. Both are enforced; the meta tag is the stricter one for
  `script-src` and the looser one for `connect-src` (F-028).
- Bundled Web Workers do not receive the configured CSP header and do not
  inherit the page meta policy, so the worker boundary is outside the policy
  (F-029).
- `core:default` is broader than the app needs; the minimum set is
  `core:event:default`, six explicit window permissions and `dialog:default`
  (F-030).
- The write guard does not yet protect a managed copy's `originalPath` (F-031).
- `glib 0.18.5` remains an accepted Linux-only advisory tracked by
  [#21](https://github.com/MajorJohnDoe/gridscalr/issues/21). The four additional
  Rust advisories are unmaintained crates with no known vulnerability.
- The ten npm moderate advisories are development-only; the production audit is
  clean (F-039).
- No new test was added in this phase. A CSP or network regression test added now
  would either fail or encode the current inconsistency, so it belongs to the
  phase that fixes it (F-028, F-029) or to phase 5 (F-032).

#### Findings

- F-028 P2 — Two page CSP policies; production keeps the dev
  `localhost:1420` HTTP/WS origins; missing hardening directives; phase 2.
- F-029 P2 — PDF.js and Tesseract workers are outside the configured CSP;
  phase 2.
- F-030 P2 — `core:default` grants unused menu, tray, image, path, webview and
  app permissions; phase 2.
- F-031 P2 — The write guard ignores `DocumentRef.originalPath`; phase 3.
- F-032 P2 — No byte limit on project or file reads; phase 3.
- F-033 P2 — Package extraction can write 16 GiB without disclosure or a free
  space check; phase 3.
- F-034 P2 — An untrusted project can reference any local path; phase 3 plus a
  documentation note.
- F-035 P2 — GitHub Actions use mutable major tags in the release build;
  phase 4.
- F-036 P3 — Windows path guarantees are not tested on Windows; phase 3.
- F-037 P3 — Test-only IPC commands are shipped; phase 2.
- F-038 P3 — `style-src 'unsafe-inline'` is forced by two static declarations;
  phase 2.
- F-039 P3 — Development-only minimatch advisory; phase 4.
- F-040 P3 — Accepted glib advisory and four unmaintained Rust crates; phase 4.
- F-041 P3 — A crashed save leaves project data in a temporary sibling;
  phase 3.
- F-042 P3 — IPC error details expose absolute paths; phase 2 or a small
  follow-up.
- F-043 P3 — PDF export embeds a wall-clock time, so the byte-comparison test is
  flaky; phase 5. Found during the phase 1 CI run, not caused by the audit
  change.

## Decisions already taken

- Autosave is an app-level preference: default on, interval 15/30/60 seconds,
  and pause for the current session.
- Structural checkpoints are still written when autosave is off or paused.
- Read-only becomes true view-only with an explicit **Take over to edit**.
- Layer hierarchy is phase 10 of 0.25.0, not part of 0.24.0.

## Workflow

Use [`conductor-prompt.md`](conductor-prompt.md). One fresh worker per phase,
independent defensive review before merge, and a green `main` before the next
phase. Phase 1 is audit-only: produce a threat model and P0/P1/P2 findings with
follow-up issues. Do not make production changes in phase 1 unless a P0 requires
it.
