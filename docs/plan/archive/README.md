# Archived planning documents

These are the implementation plans written before and during milestones 2–5. They
are kept because they record the reasoning, acceptance criteria and risk
assessments behind decisions that are now part of the product.

They are **historical and not maintained**:

- They are written in Swedish. The current documentation is in English.
- Status lines, schema versions and file names inside them describe the state at
  the time of writing, not today's code.
- Current status, deferred work and open decisions live in
  [`../../roadmap.md`](../../roadmap.md). The shipped project format is documented
  in [`../../project-file.md`](../../project-file.md).

| --- | --- |
| [Milestone 2 — Quantities and procurement](milestone-2-quantities.md) | 2A and 2B: categories, rooms, counts, deductions, waste, rounding, reports |
| [Milestone 3 — Measurement tools, scale and export](milestone-3-tools-scale-export.md) | 3A and 3B: quick areas, manual scale, locks, snapping, drawing export |
| [Milestone 4 — Images](milestone-4-images.md) | Embedded PNG/JPEG images, modes, handles, opacity, rotation |
| [Milestone 5 — TIF drawings and multiple documents](milestone-5-tiff.md) | Lossless CCITT G3/G4 import, multiple documents, append-only pages |

Git history retains the original file names and the full text; these copies differ
only by the note at the top and the English file names.
