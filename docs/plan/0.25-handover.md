## Decisions

- The run is time-boxed: no new phase starts with fewer than 45 minutes left of
  the 90-minute budget. A phase in flight at the limit is pushed and its PR is
  left open for the next run rather than merged unverified.
- Phases run one at a time because a worker checks its branch out in the shared
  `/workspace` checkout. Conductor commits happen in
  `/tmp/opencode/conduct` on `main`.
- Phase 10 is the only schema change (25 → 26). Any phase that changes
  `SCHEMA_VERSION` without the full schema gate is a stop condition.
- Phase 12 ([#58](https://github.com/MajorJohnDoe/gridscalr/issues/58)) does not
  change the schema.
- No version bump, tag or release: 0.25.0 is not approved for release.

## Verification loop

The two-tier rule in `AGENTS.md` applies:

- the **local gate** is the guard scripts, `format:check`, `lint`,
  `check:i18n`, `check:themes`, `npx tsc --noEmit` and the focused Vitest files,
  targeting under two minutes;
- **CI is authoritative** and runs the whole list on the PR head;
- heavyweight local suites run only when the change touches their area —
  `tests/robustness/` for page/save/source work, `cargo fmt/check/test --lib`
  for Rust, `test:visual` and the matching browser suite for rendered changes,
  `docs:capture` when a captured screen changed, `tauri build -- --no-bundle`
  once before the push for shell changes.

Nothing merges until its own PR and the `main` commit it is based on are green.
Attempt budget per worker: three fix → push cycles. Environment failures are
re-run once and recorded, never fixed by changing application code.

### Phase 12a — [#58](https://github.com/MajorJohnDoe/gridscalr/issues/58) TIF decoding: none, PackBits, LZW, Deflate

- **Branch:** `feat/58a-tiff-codecs`, cut from `origin/main` at `39da6ea`.
- **PR:** [#227](https://github.com/MajorJohnDoe/gridscalr/pull/227) against
  `main`, code commit `cb15a5e` plus this handover commit. Part of #58; 12b
  follows on the same issue.
- **Status:** implemented and locally verified. Schema stays 26; no migration.
- **Completed:** stripped TIFFs with compression 1 (none), 32773 (PackBits),
  5 (LZW) and 8/32946 (Deflate) now import, including horizontal predictor 2
  for 8- and 16-bit samples. Greyscale and RGB(A) at 1, 2, 4, 8 and 16 bits are
  decoded; 1-bit greyscale stays packed as a 1-bit PDF image, 2/4-bit
  greyscale expands to 8 bits, 16-bit samples use the high byte and RGBA is
  composited over white. Every TIFF strip becomes one `/FlateDecode` image
  XObject, so a decoded page has the same page size, DPI, orientation and
  multi-page behaviour as a CCITT page. The PDF metadata dates are fixed, so
  decoding the same bytes twice produces identical PDF bytes. JPEG-in-TIFF
  (6/7), tiled layouts, planar channels, palette/CMYK/YCbCr colour,
  signed/float samples, unsupported predictors, predictors below 8 bits,
  pages without strips, damaged strips and rasters over 256 MB decoded are
  rejected with a localized reason; none writes a blank or black page.
- **Modules:** pure codec modules under `src/io/tiff/`: `packbits.ts`, `lzw.ts`,
  `deflate.ts` (bounded `fflate` streaming inflate), `predictor.ts` and
  `decode.ts` (validation, strip dispatch, bit unpacking, photometric
  conversion, RGBA compositing). `src/io/tiff.ts` keeps IFD parsing and gains
  per-sample bits, ExtraSamples, SampleFormat and all four tile tags.
  `src/io/tiffImport.ts` keeps the CCITT branch unchanged and adds the decoded
  branch. No new feature directory and no `App.ts` change.
- **Decisions:** CCITT G3/G4 is detected by compression 3/4 and stays on its
  existing byte-for-byte passthrough; every other supported codec goes through
  the raster path. Decoding is per strip to bound peak memory. The decoded
  raster limit is 256 MB per page, checked before allocation; the existing
  400-megapixel and 200 MB limits still apply. 16-bit output is intentionally
  8-bit and RGBA is flattened (F-089/F-090), and predictor 2 below 8 bits is an
  explicit rejection (F-092). Colour pages still use the existing embedded
