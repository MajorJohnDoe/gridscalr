Schema stays 28. No new dependency and no new persisted field.

## Phase A — keep the straight-line guide when drawing to the I/O rail

- Issue: #377
- PR: #380
- Commit: `6b10e6c` (squash `f829e98`)
- Schema: unchanged

### Completed

- Added pure `snapAlongAxis()` and a shared `orthoPoint()` in `src/model/snap.ts`.
- `CanvasView.constrainPolyline()` tries the axis-preserving target before the
  any-angle snap, sets the snap indicator to the projected candidate and keeps
  the plain ortho result when no target is on the guide.
- Polyline creation and preview pass the raw pointer so the axis is chosen from
  the pointer, not from an already-projected snap point.
- Rail rows are covered as segment candidates; the pointer can project anywhere
  along a row.
- Tests cover vertical and horizontal row landings, off-axis port fallback, no
  target, zoom tolerance and the rail-row segment candidate.

### Modules

- `src/model/snap.ts`
- `src/canvas/CanvasView.ts`
- `src/canvas/pointer/creation.ts`
- `tests/snap.test.ts`

### Decisions

- Axis targets are preferred only when the candidate is on or near the guide.
  An off-axis port keeps today's any-angle snap instead of being projected onto
  a distant axis.
- No schema, version or dependency change.

### Checks

- Local gate, `tests/snap.test.ts`, full Vitest suite and `test:canvas` passed.
- CI green on PR head `6b10e6c`.

## Phase B — mark a channel connection in one click

- Issue: #378
- PR: #381
- Commit: `fc75795` (squash `63c9358`)
- Schema: unchanged

### Completed

- Added `src/features/railConnections/` with pure crossing and guard rules, a
  one-mutation insertion controller and the public surface.
- Right-clicking a polyline/line near a rail crossing offers **Connect to
  channel**; it inserts one existing `schematic.connection-dot` at the exact
  wire/row intersection on the wire's own layer.
- The click page point is threaded from the canvas through `App` into
  `showSelectionMenuAt`; panel menus do not offer the action.
- The action is absent in view-only/read-only sessions, on hidden or locked
  wires/layers, and away from a crossing. A visible locked rail still counts
  because the rail is not edited.
- EN/SV strings added; the connection dot is a normal symbol item, so export and
  the Markups table already handle it.

### Modules

- The action appears only when a crossing is within 12 screen px of the click.

## Phase C — continue an existing line from its endpoint

- Issue: #379
- PR: #382
- Commit: `973d841` (squash `1e1a682`)
- Schema: unchanged

### Completed

- Right-clicking within 12 screen px of a polyline's first or last vertex offers
  **Continue line here** / **Fortsätt linje härifrån**; middle vertices never do.
- The action targets the item's own draw layer, selects the polyline tool and
  starts a draft at the shared vertex. The draft carries `appendTo` and the
  finish path appends to the same item instead of creating a new one.
- Last-vertex continuation appends the tail; first-vertex continuation prepends
  the reversed tail, so the path gains no stray closing segment. The shared
  joint and duplicate consecutive points are dropped.
- The whole append is one `store.mutate(..., "change")`, so it is one undo step.
  Escape clears the draft before any mutation, leaving the item unchanged.
- Hidden/locked layers and items (inherited hierarchy locks included), measure
  layers, non-polyline items, read-only projects and view-only sessions are
  rejected by the shared guards.

### Modules

- `src/features/lineContinuation/model.ts`
- `src/features/lineContinuation/controller.ts`
- `src/features/lineContinuation/index.ts`
- `src/ui/selectionMenu.ts`
- `src/ui/panels.ts`
- `src/app/App.ts`
- `src/canvas/CanvasView.ts`
- `src/canvas/pointer/draft.ts`
- `src/canvas/draftRenderer.ts`
- `tests/lineContinuation.test.ts`

### Decisions

- The append rule works in item-local space; the controller converts the
  page-space draft points, so a transformed polyline still appends correctly.
- `CanvasView` keeps only the draft start and one delegation to the controller.
  The legacy `App.ts`/`CanvasView.ts` budgets were raised by the minimum wiring
  size (1101 → 1103 and 1560 → 1584). No new file exception was added.
- EN/SV strings added; `src/i18n/types.generated.ts` regenerated.
