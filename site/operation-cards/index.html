Operation cards

Draw an operation card in the same project as the plan

A3 templates with sheet fields, schematic symbols and page-scoped layers. The card is its own page beside the plan, so the system follows the same project number and revision.

How it works

From blank sheet to a filed card

  1. 1

    Start from a sheet template

    Create an A3 or A2 sheet and fill the title block: property, system, date, handled by and signature.

  2. 2

    Draw the system

    Place the air handling unit, ducts, valves and sensors from the schematic library. Each layer carries one part of the system.

  3. 3

    Fill the fields and export

    Complete the sheet fields, check the revision and export the page as PDF with layers and labels.

Operation cards

What the card contains

  • Sheet A3 and A2 templates with sheet fields
  • Symbols Ventilation, heating, control and electrical
  • Layers Own layers per page, lock per item
  • Export PDF with layers, labels and legend

Worked example

The sheet fields

A card that cannot be filed is not a card. Fill the same fields on every sheet so the set can be sorted by property and system.

  • Property and building
  • System and unit ID
  • Date and revision
  • Handled by and signature
  • Page number and total pages
  • Reference to the plan

Common mistakes

  • Updating the plan but not the card, so the drawing set disagrees with itself.
  • Using symbols without a legend, so the next technician has to guess.
  • Reusing one layer for several systems, which makes the export impossible to filter.
  • Exporting the wrong page range and filing a partial card.

Questions

Questions

Can I edit an existing operation card?

Yes. Import the page or a TIF and draw on top of it, or redraw it from a template.

Do I need a CAD program?

No. The sheet, symbols and text are drawn in the same app as the takeoff.

Are the symbols a certified standard?

They are drawn for operation cards and follow common HVAC practice. Check your own drawing standard before issuing a card.
