Drawing sets

Open and organise the whole drawing set

Open PDF plans, import scanned TIF pages and keep several source documents in one project. Pages are append-only, so an existing takeoff keeps its page references when a new drawing arrives.

  • PDF rendering with page thumbnails, page names, building and floor labels.
  • Lossless CCITT G3/G4 TIF import for scanned drawings, without converting the source first.
  • Multiple documents per project with new pages appended at the end, never inserted or reordered.
  • Fit, zoom, split view, explicit page duplication and page deletion with safe item remapping.

Good for: multi-sheet facilities drawings and revision sets.

Measurement

Calibrate once and measure with confidence

Set the real-world scale from a known dimension or the printed 1:N ratio, lock it against accidental changes and measure directly on the plan.

  • Multi-segment lengths, polygon areas, quick rectangles and ellipses, radius, diameter, three-point arcs, angles, slopes and volumes.
  • Snap to endpoints, midpoints and intersections between visible segments, with an adjustable threshold.
  • Labels use paper-space sizing and stay consistent on screen and in PDF exports.
  • Category, room, deduction areas and per-page scale locks keep the takeoff reviewable.

Good for: room areas, wall lengths, slopes and volume takeoffs.

Counting

Count once and review a count schedule

Count doors, windows, radiators, fixtures and your own object types. Each type can carry its own glyph and quantity, and one placed object can represent several pieces.

  • Built-in count types plus custom project types with a name and vector glyph.
  • Pieces per count object for grouped doors, windows or equipment.
  • Count schedule rows per type, a Count type column in Markups, filtering and grouping, and count legend glyphs.
  • Reusable count presets so a new project starts with the same definitions.

Good for: door schedules, window schedules and fixture inventories.

Organisation

Layers, categories and rooms keep the takeoff readable

Measurement layers and drawing layers stay separate. Within them, categories, rooms and per-item visibility make a large project easy to review and export.

  • Separate measurement and drawing layers, page-scoped and visible by page.
  • Per-item visibility and locks, with layer visibility and locking taking precedence.
  • Categories, rooms, deduction areas and measurement bulk edits.
  • Markups views with configurable columns, filters, multi-level grouping and row navigation.

Good for: projects with many rooms, buildings or revision rounds.

Annotation

Draw and annotate without leaving the plan

Add the field notes, revision marks and handoff comments your team needs on separate drawing layers, so they never mix with measured quantities.

  • Pen strokes, lines, arrows, rectangles, ellipses and highlights.
  • Revision clouds, callouts, stamps, revision deltas and text notes.
  • Resize and rotate drawings, stamps and symbols with visible handles.
  • Hidden items never render, hit-test or export; locked items stay visible.

Good for: condition notes, work orders and contractor handoff.

Facility symbols

Place searchable facility symbols

Use a built-in library of 52 original sign plates for fire, evacuation, HVAC, electrical, building and waste equipment, then review them by category and status.

  • Searchable symbol library with recent symbols and category colours.
  • Rotation, corner resizing and a 24 pt default size.
  • Inspection statuses shown as a badge on the plan and in Markups.
  • Symbol and status views for a quick facilities review.

Good for: equipment inventories, inspections and maintenance planning.

Embedded images

Keep photos and scans inside the project

Embed PNG or JPEG images such as inspection photos, detail scans or reference pictures and place them on the plan without adding another file to manage.

  • Embedded assets stored in the project file, with source images untouched.
  • Background mode below markups, or annotation mode above the plan.
  • Drag handles, opacity and rotation; images are included in PDF export.
  • Downscaling and byte limits keep a project portable.

Good for: condition photos, equipment details and site references.

Quantities

Review procurement quantities and order settings

Quantities are calculated from the same item data you measured and counted. Review gross, deduction, net, waste and order quantities before anything leaves the app.

  • Group quantities by category, room and page.
  • Waste percentage, rounding and minimum order quantities.
  • Separate quantity rows for every count type.
  • No stored summary: every report is derived from the current project.

Good for: procurement, contractor handoff and internal review.

Exports

Export the drawing, the quantities or both

Choose the output the next person needs: a marked-up drawing, a quantity workbook, a print-friendly report or the raw project data.

  • Flattened drawing PDF with page ranges, crop areas, visible layers, labels and an optional legend.
  • Quantity CSV, six-sheet XLSX workbook and print-friendly A4 PDF report.
  • Markup CSV, project JSON and PNG for other systems.
  • Exports follow the same visibility and locking rules as the canvas.

Good for: procurement packages, work orders and archive copies.

Review

Compare a reference or a revision before you act

Show the same page, a saved revision or a raw PDF drawing beside the editable canvas. The reference follows every pan, zoom and page change, but never edits the project.

  • Synchronized read-only reference pane with three source types.
  • Side-by-side or overlay comparison with adjustable opacity.
  • Changed, added and removed markups listed with warnings and row navigation.
  • Comparison PDF export without merging either source drawing.

Good for: revision review before ordering or handoff.

Search

Find text in PDF plans and scanned drawings

Search the PDF text layer across every page, or run local English and Swedish OCR on a scan and keep the results on your machine.

  • Page results, snippets and a highlighted hit on the drawing.
  • Local Tesseract OCR for scanned pages, with English and Swedish models.
  • Per-page OCR data stored in the project so a reopened scan is not rebuilt.
  • No search request leaves the app.

Good for: finding room names, equipment tags and drawing notes.

Workflow

Help, recovery and touch input in the same app

The guide, role-based workflows, shortcuts and About panel ship inside the application, next to autosave recovery and undo history.

  • In-app user guide, workflows for two roles, shortcut reference and Help search.
  • Autosave recovery, recent files and undo/redo across bulk edits.
  • Two-finger pan and pinch zoom, pen priority, palm rejection and long-press menus.
  • Project schema migration when an older project is opened.

Good for: technicians learning the app on site and teams sharing a method.
