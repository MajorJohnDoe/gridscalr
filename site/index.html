Private by default

Local-first and offline by design

GridScalr is built for drawings that should not leave the machine they arrived on. There is no server, no database in the cloud and no background service.

No account, cloud or telemetry

The desktop app reads drawings from disk and writes only where you ask it to. There is no network access, no telemetry and no automatic update service.

Source drawings are never modified

A project references the PDF or TIF by path plus a SHA-256 checksum. Every save and export refuses to overwrite a drawing that belongs to the project.

Project data stays on your machine

Projects and autosave recovery live locally. You decide where a project is saved, which pages are exported and what leaves the app.

One takeoff, every sheet

PDF takeoff for floor plans and site plans

Calibrate, measure, count and annotate the whole drawing set. PDF measurement and quantity takeoff share the same item data, and nothing is sent to a third party.

Scanned TIF/TIFF drawings with local OCR

Import scanned TIF drawings as lossless CCITT G3/G4 pages, calibrate them like a PDF and index their text with bundled English and Swedish OCR.

Count doors, windows, fixtures and custom object types

Place count objects as pieces, define your own types and review a quantity row and a count schedule per type. The Count schedule makes a door, window or fixture list without custom columns.

Calibration and measurement

Calibrate against a known dimension or enter the printed 1:N scale. Measure multi-segment lengths, radius, diameter, arcs, angles, slopes, polygon areas, volumes, quick rectangles and ellipses.

Quantities and schedules for facilities operations

Organise items by category, room and page. Review gross, deduction, net, waste and order quantities, then export a CSV, an Excel workbook or a PDF report.

Layers, markups and facility symbols

Keep measurement and drawing layers separate. Add revision clouds, callouts, stamps and text notes, or place searchable facility symbols with rotation and inspection status.

Reference pane and revision comparison

Show the same page, a saved revision or a raw PDF drawing beside the editable canvas. Pan, zoom and page changes stay in step, and the reference never edits the project.

From drawing to quantities

How it works

  1. 1

    Open a drawing

    Open a PDF plan or import scanned TIF pages. New drawings append to the project, so a full set shares one takeoff.

  2. 2

    Calibrate and measure

    Set the page scale, measure lengths and areas, count objects and annotate the plan with layers, markups and symbols.

  3. 3

    Review quantities and export

    Check gross, deduction, net, waste and order quantities, then export CSV, XLSX or a print-friendly PDF report.

Windows SmartScreen

The installers are not code-signed, so Windows may show “Windows protected your PC”. Choose More info → Run anyway after comparing the SHA-256 hash with the release checksums. Unsigned builds can also trigger antivirus false positives.

Build from source

The published installers are Windows builds. Linux and macOS builds can be produced from source with Node.js 22.12 or newer, Rust 1.77.2 or newer and the Tauri 2 platform prerequisites. 

git clone https://github.com/MajorJohnDoe/gridscalr.git
cd gridscalr
npm ci
npm run tauri build
Build from source

No code signing is used. Compare any downloaded file with SHA256SUMS.txt before running it.

Questions

Frequently asked questions

Can I measure scanned TIF drawings?

Yes. GridScalr imports scanned TIF/TIFF drawings as lossless CCITT G3/G4 pages, so you can calibrate and measure them without converting to PDF first. Local English and Swedish OCR can also index the text in a scan.

Does GridScalr work offline?

Yes. Measuring, counting, project files and exports all work without a network connection. The desktop app does not use an account, cloud storage, telemetry or an automatic update service.

Where are projects and drawings stored?

On your machine. A project stores a reference to the source PDF or TIF path plus its SHA-256 checksum, and the source drawing is never modified. Autosave recovery uses a local IndexedDB store in the app.

Can I export quantities to Excel?

Yes. The quantities can be exported as an XLSX workbook, a CSV file or a print-friendly PDF report. The workbook contains summary, category, room, page, markup and source-notes sheets generated from the same takeoff data.

Do I need to calibrate the drawing?

Yes for reliable measurements. You can calibrate a page against a known dimension or enter the printed 1:N scale, then lock the page scale so it cannot be changed by accident. Counts do not need a scale, but lengths, areas and volumes do.

Is GridScalr suitable for facilities operations and technical property management?

Yes. The workflows cover room areas, fixture and equipment inventories, door and window schedules, maintenance planning, condition notes, revision review and procurement quantities. The same user guide and role-based workflows ship inside the app under Help.
