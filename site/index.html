Private by default

Your drawings never leave your machine

GridScalr reads the drawing from disk, stores the takeoff locally and writes only the exports you ask for. There is no account, cloud or background service in between.

Source PDF or TIF drawing Referenced by path and SHA-256. Never modified.
→
Project Takeoff on your machine Layers, measurements, counts, quantities and autosave.
→
Output CSV, Excel or PDF Written where you choose. Nothing is uploaded.

No account, cloud or telemetry

Measuring, counting, project files and exports work without a network connection. There is no telemetry and no automatic update service.

Source drawings are protected

Every save and export refuses to overwrite a drawing that belongs to the project. The source file and its checksum stay under your control.

One local project, every sheet

Multiple PDFs and TIF scans share one project. New drawings append pages instead of replacing the set you already measured.

Linux and macOS builds can be produced from source with Node.js 22.12 or newer, Rust 1.77.2 or newer and the Tauri 2 platform prerequisites.

cd gridscalr
npm ci
npm run tauri build

Questions

Frequently asked questions

Can I measure scanned TIF drawings?

Yes. GridScalr imports scanned TIF/TIFF drawings as lossless CCITT G3/G4 pages, so you can calibrate and measure them without converting to PDF first. Local English and Swedish OCR can also index the text in a scan.

Does GridScalr work offline?

Yes. Measuring, counting, project files and exports all work without a network connection. The desktop app does not use an account, cloud storage, telemetry or an automatic update service.

Does GridScalr work in Swedish?

Yes. The interface, quantity reports and export headings are available in English and Swedish. Choose System, English or Svenska in Preferences; the change applies immediately, and numbers, dates and CSV follow the selected language.

Where are projects and drawings stored?

On your machine. A project stores a reference to the source PDF or TIF path plus its SHA-256 checksum, and the source drawing is never modified. Autosave recovery uses a local IndexedDB store in the app.

Can I export quantities to Excel?

Yes. The quantities can be exported as an XLSX workbook, a CSV file or a print-friendly PDF report. The workbook contains summary, category, room, page, markup and source-notes sheets generated from the same takeoff data.

Do I need to calibrate the drawing?

Yes for reliable measurements. You can calibrate a page against a known dimension or enter the printed 1:N scale, then lock the page scale so it cannot be changed by accident. Counts do not need a scale, but lengths, areas and volumes do.

Is GridScalr suitable for facilities operations and technical property management?

Yes. The workflows cover room areas, fixture and equipment inventories, count schedules for doors, windows and fixtures, maintenance planning, condition notes, revision review and procurement quantities. The same user guide and role-based workflows ship inside the app under Help.
