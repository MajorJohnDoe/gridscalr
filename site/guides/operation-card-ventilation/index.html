Draw a ventilation operation card

One air handling unit, its ducts, dampers, sensors and control points on one schematic sheet.

Short answer

Start from an operation card sheet, put the air handling unit at the centre and draw supply and extract ducts as lines. Add valves, silencers, terminals and sensors from the schematic library, snap them to the duct, tag them, and keep notes on their own drawing layer before exporting a vector PDF.

Place the air handling unit

Begin with the unit: fans, filters, heating and cooling coils, the heat exchanger and the dampers that belong to it. The schematic library has categories for Ventilation, Heat exchangers, Pumps and Control & electrical, and the demo sheet LB01 shows a complete supply and extract system.

A template sheet is not to scale, so position matters less than relationship. Keep the supply path on one side and the extract path on the other, and leave room for the control rows and tags below the drawing.

Draw the ducts and the components

Choose Pipe / duct and draw the run vertex by vertex. Segments stay horizontal or vertical unless you hold Shift for a free angle or start on an explicit snap target. Schematic symbols do not draw their own connection stubs, so draw the duct first and snap it to a port on the symbol body.

Add valves and dampers on the run, silencers where the drawing calls for them, and supply or extract terminals at the ends. Use Flow arrow to show direction. Each symbol keeps its drawing layer, rotation and visibility, and exports as vector artwork in the PDF.

Sensors and control points

Place temperature, pressure and flow sensors where the control strategy reads them, and give each one a tag in Properties → Tag. Nothing is numbered automatically: the tag is free text, so use the property's own prefix and number series. A card whose tags do not match the control system is harder to use than a card with fewer symbols.

Place the I/O rail from the Special symbol tab in the lower part of the sheet, with the input rows the controller uses, and connect control cables to it. Name the analogue and digital inputs the way the controller does. The point is not to reproduce the control program, but to let a technician trace which sensor feeds which input without opening a second document.

Keep the layers page-scoped

Draw the schematic on drawing layers, one layer per function or system part, and put site notes on a separate layer. Layers are page-scoped: the same layer name exists across pages, while visibility, lock and the item list belong to the open page. The Layers panel shows only the current page's layers.

That is what makes a clean export possible. Hide the notes layer to give the contractor a clean schematic, or hide a future phase to show only what is installed today. Hidden layers never render, hit-test or export, and a hidden group hides everything beneath it.

Export a readable PDF

Choose File → Export → Drawing PDF…. Select the sheet or the pages you need, include the visible layers, and leave Optional layers (OCG) off unless the recipient's PDF reader should be able to toggle them. The title block, revision table and sheet fields are always drawn, even when every layer is hidden, and the text stays searchable.

Check the export before it leaves the building: the tags match the control system, the flow arrows point the right way, the revision row names the change, and no layer that the recipient needs is hidden.

Common mistakes

  • Placing symbols first and hoping the duct will connect, instead of drawing the duct and snapping to the symbol port.
  • Letting the app number the equipment; tags are free text and must follow the property's series.
  • Mixing site notes into the schematic layer, so a clean export is impossible.
  • Exporting with a layer hidden that the recipient needs, then discovering it in the PDF.

Questions

Do schematic symbols draw the duct for me?

No. Draw the duct or pipe as a line and snap it to a port on the symbol body. The symbols mark the component; the line shows the connection.

Are the symbols numbered automatically?

No. Each symbol has a suggested tag prefix, but the tag is free text and nothing is numbered for you.

Can I hide the notes without hiding the title block?

Yes. Notes on their own drawing layer can be hidden, while the title block, revision table and sheet fields are still drawn into the PDF.
