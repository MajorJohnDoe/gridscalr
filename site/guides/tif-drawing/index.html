Measure a scanned TIF drawing without conversion

A scan is a drawing too. Import it as pages, calibrate it and keep the original file untouched.

Short answer

Import the TIF with File → Open drawing… and choose the pages you need. GridScalr embeds CCITT Group 3 and Group 4 scans losslessly, calibrates the page like a PDF, and keeps a colour scan in a rebuildable cache beside the project. The original TIF is never modified.

Import the scan as pages

Use File → Open drawing… or drop the TIF on the Pages panel. A multi-page TIFF becomes several pages, each with its own paper size and scale. The format is detected from the file contents, not the extension, and reduced-resolution preview images are skipped. A single-page scan skips the page picker; a multi-page file shows previews so you can clear the sheets you do not need.

Lossless CCITT and JPEG-in-TIFF

A 1-bit CCITT Group 3 or Group 4 scan is embedded without re-encoding, so the lines stay as sharp as the scan. JPEG-in-TIFF scans keep their original JPEG data, with a shared JPEGTables set joined to each strip. Greyscale, RGB and CMYK JPEG scans are supported; YCCK, JPEG 2000, tiled JPEG and tiled CCITT are rejected with a message that names the reason rather than producing a partial page.

Calibrate and measure like a PDF

A scan has no text layer and no reliable page scale, so calibration matters more than on a digital PDF. Measure a known dimension on the sheet, check it against a second dimension and lock the scale. After that, length, area, count and volume work exactly as on a PDF. Snapping helps on clean line work; on a skewed or noisy scan, compare the result with a printed dimension before you trust it.

The colour-scan cache

A decoded colour scan is the largest thing a project can contain, so it is kept out of the project JSON. The converted PDF lives in the sibling folder <project>.derived/, named by the scan's checksum, the converter version and the page count; the project file carries only a marker. Keep that folder beside the project when you move or copy it. If the cache is missing and the original scan is still where the project expects it, GridScalr rebuilds the page silently. If both are gone, a dialog names the page and offers Locate the scan….

A measured six-sheet A2 colour set took about 59 MB in the cache and only 10 kB of project JSON. GridScalr warns once when the cache reaches 160 MB or when the file plus its cache approaches the 256 MB project limit, but the warning never blocks a save. Split a large colour set into one project per building or floor.

The source is never modified

GridScalr reads the TIF and writes a derived PDF beside the project; it never writes to the scan. A save or export that resolves to a source document is refused, including through a symlink or an alternate spelling. If the scan is reissued, use Replace source… on the page card: the new TIF is converted and compared against the raw-file checksum, and pages are remapped rather than guessed. A scan that does not match the project's checksum is refused, because a different revision would change what the project measures.

Common mistakes

  • Moving the project without the .derived folder, then deleting the original scan.
  • Calibrating on a dimension that belongs to another view on the same sheet.
  • Assuming a colour scan stays small because the project JSON is small.
  • Replacing a scan with a different revision and expecting the measurements to follow.

Questions

Is a TIF converted to PDF?

Yes, internally. The converted PDF is a rebuildable cache beside the project; the original scan is never changed.

Are CCITT scans recompressed?

No. CCITT Group 3 and Group 4 scans are embedded losslessly, and JPEG-in-TIFF keeps its original JPEG stream.

What happens if the cache is missing?

GridScalr rebuilds it from the original scan when the scan is reachable. If both are gone, it asks you to locate the scan.
