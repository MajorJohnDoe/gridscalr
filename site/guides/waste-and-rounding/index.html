Quantity takeoff with waste and rounding

The order quantity is not the area. It is the net area plus the rules you set per object, rounded once.

Short answer

Calculate on the net area, add waste per object and round last. Then the order quantity is traceable: 484 m² net with 10 % waste gives 532.5 m² to order. Waste and rounding belong to the object or category, not to the report.

Net first

Start from the net: gross minus deductions. A shaft that was measured as floor should not be ordered as floor, and the deduction is what keeps the gross visible while the net stays correct.

Waste per object

Waste is a percentage on the net, set per object or category. Flooring, wall panels and surface materials rarely share the same rule, and a single percentage on the whole project hides that. Set it where the material is chosen.

Round last

Rounding is applied after waste, per object, so small items do not disappear in a report total. A door count of 14 stays 14; a 3.4 m length with 10 % waste becomes 3.74 m and is rounded once, not twice.

The order quantity

The dialog shows gross, deduction, net, waste and order quantity per room. The same numbers appear in the schedule, the Excel workbook and the print-ready PDF, because they are all derived from the objects.

Checklist before export

  • Every room has an area or a count.
  • Deductions sit in the room they belong to.
  • Waste matches the material, not the report.
  • Rounding is set per object.
  • The revision matches the plan you measured.
  • Hidden items and layers are intentional.

Common mistakes

  • Adding waste to gross instead of net, which over-orders every opening.
  • Using one waste percentage for materials with different rules.
  • Rounding per report instead of per object, so small items disappear.
  • Exporting before the revision check, so the order builds on an old plan.

Questions

Should waste be added to gross or net?

To net. Gross includes deductions that should not be ordered; waste applies to what is actually ordered.

Where do I set waste and rounding?

Per object or category in the takeoff settings, so different materials can follow different rules in one project.

Can I see the order quantity before exporting?

Yes. The order dialog shows gross, deduction, net, waste and order quantity per room.
