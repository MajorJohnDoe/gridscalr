Compare two drawing revisions before ordering

Check what changed between two revisions without touching the takeoff you are about to order from.

Short answer

Open the previous file as a read-only reference with File → Compare with revision… and review it side by side or as an overlay. The panel lists changed, added and removed markups, warns about page-count and scale differences, and can export a comparison PDF. Neither project is merged or modified.

Open the reference

Keep the current takeoff open and choose File → Compare with revision…. Pick the previous .gridscalr file. The reference opens as a read-only session beside the current project. You can also press Ctrl/Cmd+Shift+2 to open View → Reference view (same page), choose Revision in the pane toolbar and use Open…. For a raw PDF revision, choose File → Compare with drawing… instead.

Side by side or overlay

Side by side puts the two pages next to each other, which is best for checking geometry, room names and sheet layout. Overlay stacks the reference over the current drawing and gives you an opacity slider; white page areas become transparent, so moved walls and equipment stand out. The reference pane has its own page controls and Follow primary, so you can keep a detail sheet beside the sheet you are measuring.

The difference list and warnings

For a revision, the panel lists Changed, Added and Removed measurements, drawings, symbols and their properties. Click a row to jump to the page and item; added and removed items open their page in the reference pane. Read the warnings for page-count, drawing-name and scale differences before you trust the comparison. It is a comparison of measurement and markup data plus the rendered source pages, not a semantic diff of the PDF's vector operators.

Export the comparison PDF

Export PDF writes <project>-comparison.pdf with a summary and page-by-page visuals. For a revision it also includes the warnings and the difference table. The export refuses to overwrite any source drawing, so the review file can be shared without risk to the originals.

Nothing is merged

The reference is for comparison only. Selection, editing, layers and undo belong to the primary canvas, and closing the pane does not change the drawing, the project or the undo history. The reference state is not stored in the project file. When the review is done, either close the comparison or save the current project as the new working revision; the previous file stays untouched.

Common mistakes

  • Comparing two projects that use different page scales without reading the warning.
  • Deleting the previous revision before the comparison PDF is exported.
  • Expecting the reference pane to be editable; it is read-only by design.
  • Treating the difference list as a proof that quantities are commercially correct.

Questions

Does comparison merge the two projects?

No. The reference is read-only and neither file is modified. Nothing is merged or written back.

Can I compare a raw PDF instead of a project?

Yes. File → Compare with drawing… supports side by side, overlay, opacity and the comparison PDF, but it has no markup list or difference table.

What does the comparison actually compare?

Measurements, drawings, symbols and their properties, plus the rendered source pages. It is not a semantic diff of the PDF's raw vector operators.
