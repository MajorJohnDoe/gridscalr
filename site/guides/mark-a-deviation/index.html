Mark a deviation on a drawing and export it

A cloud, a callout and a status stamp turn a site observation into a drawing the contractor can act on.

Short answer

Draw the deviation on a drawing layer, not a measurement layer. Put a revision cloud around the area, add a callout with the action and a status stamp, then export a drawing PDF with the layers the contractor needs. Hidden items stay out of the export and the source drawing is never modified.

Start on a drawing layer

Drawing tools live on drawing layers, separately from measurements. Add a drawing layer for the site visit, name it clearly and make it active before you draw. Drawing layers render below measurement layers, so measurement labels stay readable. Every object can still be hidden or locked individually without changing the layer, and a hidden layer is excluded from every export just like hidden items.

Draw the revision cloud

Choose Revision cloud (D) and click each corner; close on the first point or press Enter. The cloud can be reshaped with its vertex handles. Pick Cloud + text from the tool variant if the note should travel with the cloud, and use a light fill at roughly 20–30 % opacity so the drawing underneath stays readable. Text, font size and text-box width can be edited later from Properties.

Add a callout and a stamp

Use Callout (N) when the note needs a leader to a specific component: click the object, then click where the text box should sit, and type the observation. Use Stamp (S) for a status such as INSPECTED, NOT APPROVED or a custom status. The stamp presets follow common status colours, and a placed stamp can keep its own colour override. A revision delta is available when the change belongs to a numbered revision.

Export to the contractor

Choose File → Export → Drawing PDF…. Select the current page, all pages or a page range, and whole pages or a selected crop area. Include the visible layers the contractor needs, plus labels, the calibration line and, when useful, a legend. Optional layers (OCG) and Review annotations are off by default and keep the flattened drawing intact. Hidden layers and hidden items are never exported; locked items are.

The source drawing is never modified, and GridScalr refuses to save an export over any source document in the project. Save the PDF under a name that names the building, the sheet and the inspection date.

Common mistakes

  • Drawing the deviation on a measurement layer, so it mixes with the takeoff.
  • Relying on a hidden layer that the recipient cannot see or does not open.
  • Leaving the stamp off, so the reader cannot tell whether the deviation is approved.
  • Exporting over the source drawing instead of a new file name.

Questions

Which layer should a deviation use?

A drawing layer. Measurements stay on measurement layers, and drawing layers render below them so labels stay readable.

Can the contractor toggle layers in the PDF?

Yes, if Optional layers (OCG) is enabled. Compatible readers can then switch exported layers on and off without changing the flattened drawing.

Is the source drawing changed by the export?

No. GridScalr never writes to a source document and refuses an export that resolves to one.
