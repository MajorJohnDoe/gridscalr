Quantities

From drawing to order quantity

Quantities are calculated from the objects in the project, not from a second spreadsheet. Gross, deductions, net, waste and order quantity follow every measurement and count.

How it works

Measure, set the rules, export

  1. 1

    Measure and count

    Measure areas and lengths, and count doors, windows and equipment. Each object carries category, room and unit.

  2. 2

    Set waste and rounding

    Set waste percentage and rounding per object or category, so different materials can follow different rules in one project.

  3. 3

    Review and export

    Check the net and the order quantity per room, review the revision, then export XLSX, CSV or a print-ready PDF.

What the numbers look like

Common mistakes

  • Adding waste to gross instead of net, which over-orders every opening.
  • Forgetting the deduction, so a shaft is ordered as floor.
  • Rounding per report instead of per object, so small items disappear.
  • Exporting before the revision check, so the order builds on an old plan.

Questions

Questions

Does the schedule update when I measure?

Yes. Quantities are derived from the objects; there is no separate table to update.

Can I export to Excel?

Yes. The workbook has summary, category, room, page, markup and source sheets, built from the same data.

What about counted objects?

Each count type gets a row with pieces per object and a total, so doors, windows and fixtures can be ordered by type.
